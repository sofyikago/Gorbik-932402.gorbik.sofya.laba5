# Лабораторная работа №5

DOM и взаимодействие с элементами страницы. Вариант 1 — «Студент-разработчик»: управление проектами.

## Реализовано
- Поиск элементов: `getElementById` для кнопок, `querySelector` для контейнера проектов, `querySelectorAll` для карточек
- «Добавить проект»: название и описание через `prompt`, карточка `<article>` с `<h3>`, `<p>` и кнопкой создаётся через `document.createElement` и добавляется через `appendChild`
- «Удалить последний»: удаляет последнюю карточку через `remove()`; если карточек нет — в консоль «Нет проектов для удаления» и `alert` «Список пуст»
- Переключение темы: кнопка меняет класс `theme-light` / `theme-dark` у `<body>`, каждый класс задаёт свои значения CSS-переменных
- «Свернуть проекты»: добавляет и убирает класс `hidden` у контейнера, меняет текст кнопки и атрибут `aria-expanded`
- Обработка ошибок: перед запуском проверяется наличие контейнера и всех кнопок; если элемент не найден — ошибка в консоль, скрипт не выполняется
- `localStorage`: список проектов сохраняется при добавлении и удалении, тема — при переключении; при загрузке страницы всё восстанавливается
